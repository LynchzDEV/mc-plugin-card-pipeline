## Shared contract (both paths depend on these names; do not rename)

Card folder `<card-dir>/`:
- Written by `land.ts`: `card.md`, `shots/*.png`, `fields.json`.
  - `card.md` sections in order: `# <title> (<id>)`; `## Fields` (Log Type label, Status, Tags, Planning label, SELLER ID when set, Parent id when the card is itself a subtask); `## Description` = `markdown_description` with numbering kept and every `![...](url)` replaced by `![shots/<item>-<n>.png](shots/<item>-<n>.png)` where `<item>` is the top-level numbered item the image sits under (`0` above the first item or on an unnumbered card) and `<n>` the order within that item; `## Comments` = human comments only, oldest first, `- **<author>** (<YYYY-MM-DD>): <text>`, dropping any comment that contains two U+2063 characters (adjacent or not), the footers `[🤖 Biz ยังไม่ต้อบตอบ อันนี้บอทจ้า]` / `[🌚Biz ยังไม่ต้อบตอบ อันนี้บอทจ้า]`, a first line `⚠️ ความคิดเห็นนี้สร้างโดย AI`, or the triage shape (`พร้อมทำได้เลย:` and `เหตุผล:` both present); `## Linked cards` = `- <name> (<id>) — <status>` from `linked_tasks`/`dependencies` when present; `## Attachments not in description` = titles.
  - `fields.json`: `{"id","title","logType": "Bug"|"SuperBug"|"CR"|"Question"|"Issue"|"Function"|"BizTask"|null, "numberedItems": <count of top-level `^\d+\. ` lines>, "subItems": ["3.1",...], "planning": {"current": <label|null>, "latestAiSprint": {"id","label"}|null, "options": [{"id","label"}]}, "sellerCodes": ["S0...."], "parent": <id|null>, "subtasks": [{"id","name"}]}`.
